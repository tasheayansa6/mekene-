# Busa Mekene Eyasus Church

Church website and member platform (Next.js + Prisma + SQLite).

Repository: [github.com/tasheayansa6/mekene-](https://github.com/tasheayansa6/mekene-)

## Local development

```bash
cp .env.example .env
npm install
npx prisma migrate deploy
npx prisma db seed
npm run dev
```

Open http://localhost:3000

## Deploy on Render

1. Push this repo to GitHub (already configured as `origin` when pushed).
2. In [Render](https://dashboard.render.com): **New → Blueprint** → connect `tasheayansa6/mekene-`.
3. Render reads `render.yaml` and creates the web service + 1GB disk at `/var/data`.
4. Set these env vars in the dashboard (required):

| Variable | Example |
|----------|---------|
| `APP_URL` | `https://your-service.onrender.com` |
| `CORS_ALLOWED_ORIGINS` | same as `APP_URL` |
| `CSRF_TRUSTED_ORIGINS` | same as `APP_URL` |
| `SEED_SUPER_ADMIN_EMAIL` | your admin email |
| `SEED_SUPER_ADMIN_PASSWORD` | strong password |

`AUTH_SECRET` is auto-generated by the blueprint.

5. After the first successful deploy, SSH or use the Render shell once to seed:

```bash
npx tsx prisma/seed/index.ts
```

Or add a one-time job. Do **not** leave demo seed passwords in production long-term.

6. Custom domain (optional): Render → Settings → Custom Domains → point DNS to Render.

### Important notes

- **SQLite + disk**: data lives on the Render disk (`DATABASE_URL=file:/var/data/prod.db`). Back up the disk. For heavy production use, migrate to Render PostgreSQL later.
- **Never commit** `.env` or live payment/Telegram secrets.
- Health check: `GET /api/v1/health`
